Veelgestelde vragen

Wat is The Mob State?

The Mob State is een text-based mafia game in de browser. Je speelt via menu’s en timers, niet via 3D-actie.

Wat is een text-based mafia game?

Een mafia-/crimespel met tekst-UI: acties, cooldowns en lange progressie (geld, rank, crew).

Kan ik op mijn telefoon spelen?

Ja. Mobiele browser of PWA op het beginscherm. Zelfde account via login (wachtwoord, Google of Facebook).
