Wat is een text-based mafia game?

Een text-based mafia game is een spel waarin je keuzes maakt via tekst en menu’s. Je bouwt langzaam een imperium op met korte acties die je door de dag heen doet.

Kan ik spelen op mobiel?

Ja. The Mob State werkt in je mobiele browser en als PWA.

Is het gratis?

Je kunt gratis starten en spelen. Premium is optioneel.
